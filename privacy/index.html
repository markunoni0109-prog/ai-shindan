プライバシーポリシー

運営：AI HUNTER ／ サービス：LOTO6 NEXUS ／ 制定日：2026年10月22日

本サービスは試験運用中です。内容は、正式運用の開始時に改めて見直します。

1. 取得する情報

  • 決済情報：Stripe社が処理します。当運営はカード番号を取得・保存しません。
  • メールアドレス：決済時に入力された場合、ハッシュ化した値のみ保存し、原文は保存しません。
  • 予測記録：生成した数字、日時、識別用ID。購入者の氏名等とは結びつけずに保存します。
  • 通信情報：不正利用や過度なアクセスを防ぐため、IPアドレスを一時的に利用します。
  • お問い合わせ：お問い合わせ時にいただいたメールの内容。

2. 利用目的

  • 予測の生成・保存・表示・追跡
  • 決済の確認と、返金等の問い合わせ対応
  • 不正利用の防止、サービスの維持・改善

3. Cookieと端末への保存

Cookieは使用しません。アクセス解析・広告タグも使用していません。ブラウザの機能（localStorage、sessionStorage）に、匿名ID、購入した予測を閲覧するための鍵、決済の引き継ぎ情報を保存します。ブラウザのデータを消去すると、これらは失われます。

4. 外部サービス

  • Stripe（決済）
  • Cloudflare（サイトの配信、Worker、データベース）
  • GitHub Pages（サイトの配信）
  • Google Fonts（フォントの読み込み。その際、閲覧者のIPアドレスがGoogleに送信されます）

5. 第三者提供

法令に基づく場合を除き、本人の同意なく個人情報を第三者に提供しません。上記の外部サービスには、業務の実施に必要な範囲で情報が渡ります。

6. 開示・削除の請求

保有する情報の開示・訂正・削除は、local.maps.jp@gmail.com までご連絡ください。ただし、公開済みの予測記録は、購入者を特定できない形で保存されているため、削除できない場合があります。

7. 変更

本ポリシーは必要に応じて変更し、このページで告知します。
