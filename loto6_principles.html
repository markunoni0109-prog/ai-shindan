1研究の目的

ロト6の過去抽選データを対象として、出目の構造・頻度・間隔・連番・ゾーン・合計値・数字間の関係などを統計的に分析する。

本研究では、既存の分析手法を正しいものとは仮定しない。発見された特徴はすべて仮説として扱い、

観測 → 理論値との比較 → 統計検定 → 期間分割 → OOS検証

の順で検証する。有効性が確認できない特徴は削除する。

2これまでに発見された主要仮説

人間によるデータ観察から、以下の特徴が発見された。合計値による3段階(LOW：合計110以下／MID：合計111〜150／HIGH：合計151以上)。実データでは、LOW約22.1%・MID約52.3%・HIGH約25.6%という分布が確認された。この分布は完全ランダムでも発生する範囲に近く、独自の偏りとは確認されていない。したがって現在は、「予測法」ではなく「出目構造を分類するための研究上の区分」として扱う。

3段階別連番

観測された連番率：LOW約59.6%・MID約49.7%・HIGH約59.3%。低・高で連番率が高く、中間で低くなる特徴が確認されたが、ランダム組合せでも同様の構造が発生することが確認された。したがって、特別な予測能力を持つ特徴とは認定しない。連番率そのものを予測ルールとして固定しない。

4特定連番ペア・3連番

過去データから、1-2／3-4／4-5／21-22／22-23／24-25／41-42／42-43などの頻出ペア、1-2-3／4-5-6／17-18-19／21-22-23／24-25-26／37-38-39／40-41-42などの3連番が観察された。しかし、AIによる検証では、現時点でランダム揺らぎを超える再現性は確認されていない。特定連番を有力数字として扱うルールは採用しない。

5段階間の遷移

LOW・MID・HIGHについて、「前回HIGHだったから次回LOWになりやすい」などの遷移仮説を検証した。結果、前回の段階によって次回の段階が大きく変化するという統計的証拠は確認されなかった。

検証者p値
Gemini0.6884
Claude0.835

いずれも独立性を否定できない結果。段階遷移を予測ルールとして採用しない。

6LOW欠損後のLOW復動

LOW＝1〜14として、前回LOWが0個だったケースを調査。結果：176回中163回で、次回LOWが1個以上(163/176＝92.61%)という高い観測値が確認された。しかし完全ランダムでも、次回LOWが1個以上となる確率は約92%である。したがって、92.61%という数字自体は興味深いが、現在のところ予測上の優位性とは認定しない。「LOW欠損の反動」という説明は禁止する。

7差2（1個飛ばし）

数字を昇順に並べ、隣接数字との差が2になる組を「差2」と定義。前回に差2が2組以上存在したケースについて、次回に差2が1組以下となるケースを調査した。

項目値
観測値220 / 238 = 92.44%
ランダム基準約88.9%

観測値はランダム基準より高かった。ただし、期間分割・OOSで再現性が十分確認できていないため、現時点では採用確定しない。「研究継続候補」とする。

8これまでの総合判定

現時点で、「次回抽選に対する予測能力が統計的に確認された特徴」は存在しない。一方で、研究対象として価値のある現象は存在する。

9GeminiとClaudeの役割から得られた結論

Gemini

大量データから特徴を発見・集計する能力を利用する。特に、人間が発見した仮説を数値化する役割を担当。

Claude

Geminiや人間が発見した仮説を、ランダム基準・統計検定・期間分割・OOSによって反証する役割を担当。

ORBIT / OpenAI

両AIの結果について、定義・計算条件・結論の整合性を確認する監査役として扱う。

10今後の研究方針

今後は「新しいルールを増やす」ことを改善とはしない。改善とは、無効な特徴を削除し、有効性が確認された特徴だけを残すことと定義する。特に今後は以下を優先する。

  • GAP研究 — 理論期待値・実測GAP・GAP分布・極端な空白期間・数字ごとの差・時系列安定性
  • ペア研究 — 43数字から作られる903ペアの共起頻度・理論期待値・有意差・多重比較補正・OOS再現性
  • 個別数字研究 — 出現頻度・GAP・長期/短期トレンド・理論値との差・時期による変化

11絶対ルール

ロトハンターでは、以下を禁止する。

  • 「当たりそうだから採用」
  • 「一度当たったから有効」
  • 「AIが強いと言ったから採用」

採用には、明確な定義・理論基準・統計検定・複数期間での再現性・OOS検証・再現可能なコードを必要とする。そして、結果が理論を否定した場合は、理論を捨てる。これをロトハンターの研究原則とする。

総合結論

これまでの研究で最も重要だった発見は、

「人間が見つけた特徴の多くは、本当にデータ上に存在する。しかし、その特徴が存在することと、予測能力があることは別問題である」

ということだった。したがって今後のAI HUNTERは、

発見 → 数値化 → 反証 → 再検証 → 生き残った特徴だけを研究資産として保存

という方式で進める。既存ロジックを守ることではなく、既存ロジックを壊せるAIを作る。これを今後のロトハンタープロジェクトの基本方針とする。
